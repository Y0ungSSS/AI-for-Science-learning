# AI for Science · 两棵研究树

> 读论文不是为了堆收藏，而是理解**什么问题还没解决**、**已有方案为什么有效/失效**，并把有价值的想法转化为可执行的研究实验。

## 主要入口（只需要看这两个文件）

| 入口 | 解决什么 | 什么时候打开 |
|---|---|---|
| **[问题树](调研/问题树.md)** | Research Problems：问题、未解决的难点、证据缺口、优先级、可证伪实验与 Codex 任务起点 | 找研究灵感、选实验时 |
| **[研究树](调研/研究树.md)** | Mechanisms & Evidence：代表论文、方法机制、区别、受控证据与评测协议 | 想知道别人做到哪里、选 baseline 时 |

**建议阅读路径**：问题树中的 `Q` 编号 → 研究树中 `A–I` 方法节点 → 原论文 / benchmark → 定义实验 → 用实验结果反过来更新问题判断。

## 当前基线和维护原则

- 研究树依据 2026-09-26 的大调研及随后经核对的 **119 篇纳入语料**建立；**9 个领域、29 个机制/决策簇、8 个评测层级/协议轴**。这是历史核对量，不代表每天增加论文。
- 此后每日搜索 AI for Science / AI Scientist / autonomous scientific discovery 新论文；将相似方法合并到已有簇，只有真正的新问题、新机制或重要反证才改变树。
- **每日只维护 `调研/问题树.md` 与 `调研/研究树.md`**。不为了每天有更新而收录论文，也不按论文名称长新枝。
- 仓库过去的论文索引、语料库、报告、学习笔记继续保留作为**历史参考材料**，无需日常阅读，也不再作为自动更新目标。
- 树中“已有证据”不等于我们已复现实验；问题树中的实验草案是研究建议，需先做可行性关口与公平 baseline 设计。

完整使用规则见[调研入口](调研/README.md)。
