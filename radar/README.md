# Paper Radar（历史候选工作流）

本目录保存早期论文候选筛选方法与淘汰记录，**不是当前每日自动调研的写入目标**。

## 历史分类

- **A**：值得进入机制比较的关键机制、评测协议、真实科研闭环或重要反证。
- **B**：有参考价值，但主要是已有机制的组合、迁移或增量改进。
- **C**：缺乏独立研究问题、机制贡献或可信评测，暂不纳入。

## 当前执行规则

当前研究状态统一维护在[研究树](../调研/研究树.md)与[问题树](../调研/问题树.md)：

1. 搜索近 24–72 小时的论文，核对原始来源、首次提交与更新日期。
2. 对照研究树已有 A–I 机制和最近 anchor，记录差异与证据限制。
3. 只有真实机制增量或重要反证才更新研究树；只有开放问题判断变化才更新问题树。
4. 没有结构性变化时不为了凑数量写入，也不自动生成日报、月度 Radar 或候选清单。

旧有 `radar/` 文件保留供追溯。若未来恢复独立候选工作流，应先重新明确维护范围，避免与双树重复。
