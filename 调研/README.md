# AI for Science 调研

这个目录是本仓库今后**唯一持续维护的 AI for Science 调研入口**。

目标不是按日期堆论文，而是维护一个 living research tree（持续演化的研究树）：

```text
新论文
  ↓
它到底解决哪个 Research Problem？
  ↓
和树上已有方法相比，是真新增机制，还是相似改进？
  ↓
已有分支 ──→ 挂进去并补充差异
新机制   ──→ 新增子节点
新问题   ──→ 新增主分支
无实质新增 ─→ 不扩树
```

## 当前文件

- [研究树](研究树.md)：核心资产。按研究问题与机制组织。
- [论文池](论文池.md)：代表性论文与新论文的简短结构化卡片。
- [初始大调研（2026-09-26）](初始大调研_2026-09-26.md)：本轮建树依据。
- [更新记录](更新记录.md)：每天记录是否有结构性变化。

## 准入标准

一篇新论文至少满足下面一项，才进入正式研究树：

1. 提出了新的 Research Problem；
2. 对已有问题提出了明显不同的机制；
3. 提出了新的 evaluation protocol / benchmark；
4. 构成更强的真实科学闭环；
5. 对已有结论给出重要反例、失败模式或验证结果。

普通的 “LLM + RAG + multi-agent + tool use” 组合，即使很新，也不因工程堆叠而进入主树。

## 每日维护规则

每日只做增量：

1. 检查过去 24–72 小时论文；
2. 与 [研究树](研究树.md) 比较；
3. 决定：不收录 / 加入已有节点 / 新增子节点 / 极少数情况下新增主分支；
4. 每篇正式收录论文只记录：
   - Problem
   - Core mechanism
   - Compared with existing branch
   - Tree position
   - Genuine addition
5. 如果当天没有实质性新增，只在 [更新记录](更新记录.md) 标记“无结构性更新”。

## 一个重要原则

树的分类允许被后续论文推翻。

如果连续出现多篇论文证明两个节点本质相同，就合并；如果原来一个大节点逐渐分化出明显不同的问题，就拆分。这里维护的是研究地图，不是固定目录。
