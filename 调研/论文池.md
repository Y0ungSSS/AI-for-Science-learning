# 论文池

> 这里只收“能改变研究树”的代表性论文，不追求数量。

## 核心系统与机制

### The AI Scientist
- **Problem**: 端到端自动化 ML research。
- **Core mechanism**: idea generation → experiment → analysis → paper。
- **Compared with existing branch**: 早期端到端基线。
- **Tree position**: C / D / G。
- **Genuine addition**: 把 autonomous research pipeline 作为完整系统问题。
- Link: https://arxiv.org/abs/2408.06292

### The AI Scientist-v2
- **Problem**: v1 依赖模板，探索空间受限。
- **Core mechanism**: progressive agentic tree search + experiment manager。
- **Compared with existing branch**: 从单路线迭代推进到多分支实验搜索。
- **Tree position**: C2。
- **Genuine addition**: end-to-end research 中的 structured tree search。
- Link: https://arxiv.org/abs/2504.08066

### Co-Scientist
- **Problem**: 复杂科学问题中的 hypothesis generation 与 refinement。
- **Core mechanism**: generation / reflection / ranking / evolution + tournament + test-time compute。
- **Compared with existing branch**: 强化 hypothesis search，而非完整自动执行。
- **Tree position**: A1 / A2 / B3。
- **Genuine addition**: 大规模并行 hypothesis evolution，并有真实生物实验验证。
- Link: https://doi.org/10.1038/s41586-026-10644-y

### ERA
- **Problem**: scientific software 开发慢，候选方法空间巨大。
- **Core mechanism**: LLM code mutation + tree search + machine-scored objective。
- **Compared with existing branch**: 把 scientific coding 变成可评分搜索问题。
- **Tree position**: C2 / D1。
- **Genuine addition**: scorable scientific software search，在多个科学任务上形成强实证。
- Link: https://doi.org/10.1038/s41586-026-10658-6

### SciNav
- **Problem**: scientific coding 中通常没有可靠 absolute score。
- **Core mechanism**: Top-K Comparative Tree Search + pairwise Frontier Comparator。
- **Compared with existing branch**: ERA 依赖明确 score；SciNav 尝试用 relative judgment 导航。
- **Tree position**: B3 / C2 / D1。
- **Genuine addition**: 将 pairwise relative evaluation 嵌入搜索控制。
- Link: https://arxiv.org/abs/2603.20256

### SAGA
- **Problem**: 科学优化通常把 human-specified objective 当作固定真值，但目标可能本身有问题。
- **Core mechanism**: outer loop evolution of objectives + inner loop optimization。
- **Compared with existing branch**: 不只是搜索 solution，也搜索 objective。
- **Tree position**: C4。
- **Genuine addition**: goal/objective evolution。
- Link: https://arxiv.org/abs/2512.21782

### Robin
- **Problem**: hypothesis generation 与实验结果分析之间缺少连续反馈。
- **Core mechanism**: literature agents + experimental planning + Finch data analysis + updated hypotheses。
- **Compared with existing branch**: 从“生成 idea”推进到 lab-in-the-loop feedback。
- **Tree position**: D2 / D4 / E2。
- **Genuine addition**: 真实实验结果进入下一轮 hypothesis generation。
- Link: https://doi.org/10.1038/s41586-026-10652-y

### Data-to-Paper
- **Problem**: autonomous research 结果缺少可追溯性。
- **Core mechanism**: stepwise research + backward information tracing。
- **Compared with existing branch**: 相比只输出 paper，更强调 claim/data/code traceability。
- **Tree position**: F3。
- **Genuine addition**: backward-traceable autonomous quantitative research。
- Link: https://doi.org/10.1056/AIoa2400555

## Evaluation / Benchmark

### ScienceAgentBench
- **Problem**: 在声称 end-to-end automation 前，先验证每个科学工作步骤是否能做对。
- **Core mechanism**: 102 个真实论文任务，统一为可执行 Python program，并评价 execution/result/cost。
- **Tree position**: G1 / D1。
- **Genuine addition**: 真实科学任务 + executable graded evaluation。
- Link: https://arxiv.org/abs/2410.05080

### RExBench
- **Problem**: coding agent 能否真正实现“新的 research extension”？
- **Core mechanism**: paper + codebase + expert-written extension instruction → execute patch → automatic success criteria。
- **Tree position**: G2 / D1。
- **Genuine addition**: 从普通 scientific coding 推进到 research extension implementation。
- Link: https://arxiv.org/abs/2506.22598

### FIRE-Bench
- **Problem**: 怎样可验证地评估 end-to-end scientific discovery？
- **Core mechanism**: 从已发表论文构造 constrained rediscovery；隐藏方法和结论；claim-level precision/recall/F1；error taxonomy。
- **Tree position**: G3 / E3。
- **Genuine addition**: 开放式探索与外部 ground truth 结合，并能定位 planning / implementation / execution / analysis failure。
- Link: https://arxiv.org/abs/2602.02905

### AstaBench
- **Problem**: 不同 scientific agents 的 benchmark 环境、工具、成本不可比。
- **Core mechanism**: 2400+ tasks + standardized scientific environment + controlled tools + cost accounting。
- **Tree position**: G4 / G6。
- **Genuine addition**: evaluation protocol 和环境控制本身成为研究贡献。
- Link: https://arxiv.org/abs/2510.21652

### LABBench2
- **Problem**: biology benchmark 太偏知识题，缺真实 scientific work。
- **Core mechanism**: ~1900 个更现实 biology research tasks。
- **Tree position**: G1。
- **Genuine addition**: 从知识/推理推进到更真实的科研能力测量。
- Link: https://arxiv.org/abs/2604.09554

### SoundnessBench
- **Problem**: AI Scientist 在执行前能否识别方法上不 sound 的 proposal？
- **Core mechanism**: 1,099 ICLR-derived proposals + reviewer soundness labels。
- **Tree position**: B1 / G5。
- **Genuine addition**: 将 proposal-stage methodological soundness 单独拆成 benchmark。
- Link: https://arxiv.org/abs/2605.30329

### Enabling AI Scientists to Recognize Innovation (RND)
- **Problem**: novelty evaluation 跨领域不稳定。
- **Core mechanism**: Relative Neighbor Density。
- **Tree position**: A3 / G5。
- **Genuine addition**: domain-agnostic relative local-density novelty metric。
- Link: https://arxiv.org/abs/2503.01508

## Reliability / Critical studies

### The Ideation-Execution Gap
- **Problem**: idea-stage 评分是否能预测真正执行后的研究价值？
- **Core mechanism**: 43 名 expert researcher 实际执行 randomly assigned human/LLM ideas，再 blind review。
- **Tree position**: B2。
- **Genuine addition**: 用真实 execution 证明 ideation score 会系统性高估部分 LLM ideas。
- Link: https://arxiv.org/abs/2506.20803

### The More You Automate, the Less You See
- **Problem**: final paper 看起来正常时，内部 research workflow 是否隐藏系统性错误？
- **Core mechanism**: controlled tests of benchmark selection、data leakage、metric misuse、post-hoc selection bias。
- **Tree position**: F3 / G7。
- **Genuine addition**: 证明 full trace/code 比 final paper 更适合审计 AI Scientist。
- Link: https://arxiv.org/abs/2509.08713

### Autonomous Research Agents: A Survey of AI Scientists and the Verification Gap
- **Problem**: autonomous research 的 claim 是否真正可验证？
- **Core mechanism**: 对 runnable AI scientist systems 做 lifecycle/autonomy/artifact/novelty/auditability coding。
- **Tree position**: F3 / G7。
- **Genuine addition**: 把瓶颈明确从“能不能跑完”推进到“reviewer 能不能验证 claim”。
- Link: https://arxiv.org/abs/2608.05179

### The Hitchhiker's Guide to Autonomous Research
- **Problem**: scientific agents 缺统一 taxonomy。
- **Core mechanism**: capability envelope + capability maturity。
- **Tree position**: overall taxonomy。
- **Genuine addition**: 同时区分“覆盖了多少科研流程”和“真实条件下有多可靠”。
- Link: https://doi.org/10.1109/TPAMI.2026.3721500

- generic multi-agent role decomposition
- literature RAG
- ordinary web search / tool use
- self-reflection
- generic critic
- simple best-of-N
- single-score LLM-as-a-Judge
- fixed pipeline orchestration
